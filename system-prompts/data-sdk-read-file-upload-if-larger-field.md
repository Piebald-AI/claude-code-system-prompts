@internal When true, and with no `anchor`, the caller wants the whole file. A file over both `max_bytes` and 1,000,000 bytes that every gate has passed is uploaded as SendUserFile uploads a file, where that tool could, and the answer names the upload in `file_uuid`; with or without it, such an answer has empty `contents` and `truncated` true. It comes when the upload has ended, which can take minutes. Such requests are served one at a time, and the newest upload is named again for ten minutes while the file is unchanged. A CLI that predates it and a session that reads through a tool container ignore it.
