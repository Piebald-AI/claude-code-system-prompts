@internal When the session's files were usable, for a session whose launcher can hold tool calls while its hooks still fetch those files. Sent only by an internal build that a self-hosted runner started, together with time_to_request_ms. first_result_ms: from the turn's start until the end of the first call that a hold can stop, made by the model or a subagent (also one left running by an earlier turn), whether or not a hold stood and whether the call ran, failed or was refused; a stopped call does not count; it includes the permission step; absent where the turn had no such call. holds: one entry for each name under which hooks held tool calls since the previous result that carried this field, without those that began after the turn's first model request, which are dropped if they have ended and otherwise wait for the next result; empty where none stood. name: the hook's holdTools value, or empty if it cannot be shown. began_ms: when the first of them began, from the turn's start, under zero if earlier. held_ms: from then until the last of them ended. end: how that last one ended (well, failed or timed_out), or open if one still stood as the result was built, to which held_ms then runs; an open hold is listed again on the next result.
