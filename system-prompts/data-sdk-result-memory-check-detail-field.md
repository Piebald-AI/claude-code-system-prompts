@internal How the turn went about its memory check, the request that asks the session server whether the account's memory has changed. Present, in a cloud session that makes such checks, on the result of a turn that was handed to the model loop, stopped or not; absent on a local command's. A turn that will wait for the answer can first be held until the request is sent, which the memory_send_wait phase times. flag: the hold's feature flag as the turn started (1 on in claude-code-server, 2 on in every cloud worker, 0 for anything else); absent where the process's flags were not fresh. hold: off (not on for this worker), not_due (the turn was not expected to wait, or that could not be told), nothing_to_send (the request had already been sent or answered, none was due, or it is one the server may hold, which the wait replaces, or joins where only the boot grace holds the turn back while the server picks memory files for its message), or how the hold ended: sent, cap (its time limit came first), abort (the turn was stopped), failed (the request ended before it was sent). wait: went_on (the turn did not need its own check's answer, took one that was asked for ahead of the message, or the server had stopped the checks), answered, cut (the wait for the answer ran out), unanswered (the request was refused or failed); grace_answered, grace_cut and grace_unanswered say the same of a turn that waited only because the last answer was still the worker's start-up read and older than the boot grace (flag tengu_kind_flute; with it off, the default, these never appear); absent where the turn was stopped first or never came to that wait. wait is decided the same way with the hold on and off. requests: how many such checks the process has started since the last turn that reported this number, whether at start-up, ahead of the message, after the previous turn or for this turn, counting one refused before it was sent; 9 means 9 or more; present with wait. boot_age_ms: how long before the turn came to its memory check the last answered check was sent, in ms, while that check is still the worker's start-up read (normally on a worker's first turn only: any later answer replaces it); absent once a later check has answered, before any check has answered, and where the server had stopped the checks or says that no turn waits. It is the age the boot grace (tengu_kind_flute) is compared with, written whether that flag is on or off.
