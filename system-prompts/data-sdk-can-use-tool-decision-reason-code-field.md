@internal A closed-set code for a reason a host can act on, beside decision_reason_type (whose values are unchanged, so type-keyed host policy decides as before): 'outside_reads_blocked', 'memory_paused', 'classifier_transcript_too_long', 'org_ask_ceiling' (the MCP tool's ceiling, toolPermissions, is 'ask', and an ask rule or the ceiling itself raised the ask: type 'rule' or 'other'; or the limit on the connector behind the ask is 'ask' or could not be read, with any type), 'denial_limit_host_reset' (the prompt raised at three or more blocks in a row, by auto mode or by the Chrome tools' check outside it, but not the one at twenty blocks in all, sent only when the spawn environment sets CLAUDE_CODE_HOST_ALLOW_RESETS_DENIAL_STREAK, no org_ask_ceiling applies and nothing else takes the request_id off the pending_action; requires_user_interaction is true). The type also lists auto_mode_ values, which are sent on system/permission_denied only, never on this request. Absent for every other reason; new values are additive.
