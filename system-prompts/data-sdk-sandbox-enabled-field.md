@internal Whether this process runs its shell commands in Claude Code's command sandbox as this frame is built, whichever setting, policy or force turned it on. A host that runs programs of its own in the session's folders (Claude Desktop's git) reads true as: what this session wrote there is a sandboxed writer's. 'unknown' when the read failed, which such a host treats as it may be on. Omitted from the redacted init sent over the Remote Control bridge and by the hosted worker; absent means no claim, never off.
