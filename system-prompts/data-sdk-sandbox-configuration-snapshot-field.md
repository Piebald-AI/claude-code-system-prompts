The lists that the sandbox running in this process was last given, Claude Code's own entries included: the rows of the terminal's Config tab except the excluded commands. It comes from the installed configuration, not from the settings, except that allowManagedDomainsOnly, which is enforced live, is read live, and that own_proxy goes by the start. Sent only when the request asks, the sandbox has finished starting, its proxy started with a way to ask about an unlisted host, and Claude Code knows of no fault that keeps it from running commands. It says what the sandbox was given, not that a command was tried. Never sent on native Windows or under subprocess scrub.
