**If it has none, offer the `ant` sign-in first and an API key second** (no browser on this machine: read that bullet first). `ant auth login` opens a browser tab where the user signs in to the Claude Console and picks a workspace; API usage is billed to the Console organization, never to a claude.ai plan. It saves tokens under `~/.config/anthropic/`, creates no API key and adds no credits. In Claude Code, ask the user to type `! ant auth login` at the prompt (`!` runs it outside the sandbox), or to run it in a terminal of their own; don't run it yourself unless they ask. Tell them first that this needs a Console account, separate from claude.ai (if they have none, that tab lets them create one), to approve in the tab and to paste nothing here: the link it prints and its `paste the code here` work only in a terminal of their own. Then make one real call (`ant models list` is free, or run their code) before you say it works: `ant auth status` sends no request. Tell them too that Claude Code keeps its own `/login`; if that stops working, Claude Code falls back to this sign-in and bills the API organization.
