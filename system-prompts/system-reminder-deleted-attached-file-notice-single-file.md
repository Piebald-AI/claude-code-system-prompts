What you said about it up to now, you said while it was in this chat. It is not in this chat now, so give no new detail of it. Do not open or recover any saved copy of it, even by its path. If the person asks about it or asks you to open it, tell them that it was deleted. The place of this note says nothing about the person's message above it: that message can be about another file. Before you call a file deleted, find which file the person means.
