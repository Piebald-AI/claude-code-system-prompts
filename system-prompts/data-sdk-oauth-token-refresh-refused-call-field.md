The kind of call that the server refused. 'model': a call to the model, which fails at once if the host answers with the same token or none, so the host renews. 'connector': a request to a claude.ai connector. 'other': neither, at a call site that someone has checked: its failure on an unchanged token ends no turn, start or session. To 'connector' or 'other' the host may first ask the server whether the token that it holds is still good, and keep it: it then answers with that token, which is no fault to these two; if the CLI held another, it takes this one. The check and the answer must fit well inside the CLI's 30 s limit, because a model call that joined the ask shares a timeout and fails. Only with token_state 'refused'. Absent on a 'refused' ask: the call site sets none, or the CLI is older, and the host renews, as before the field: such an ask can come from a call whose failure ends a turn. A caller does not settle for the answer 'no new token' to an ask that wanted less than its own ('not_refused', then 'connector' or 'other', then no refused_call, then 'model'): it asks again, and the host judges that ask on its own. A host takes any other value as absent.
